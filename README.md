# Skill Swap

## Description
Skill Swap is a peer-to-peer platform where college students and recent graduates
trade or pay for help learning new skills, from tutoring and test prep to
tech skills and resume coaching. This repository contains the homepage for the
Sprint 1 MVP.

## Technologies Used
- React 18 (component-based UI)
- Vite (dev server and build tool)
- HTML5 (semantic markup) and CSS3 (Flexbox and Grid)
- JavaScript (ES modules, React hooks)
- Git and GitHub (feature branches and pull requests)

## Running Locally
```
npm install
npm run dev
```
Then open the local URL printed in the terminal (usually http://localhost:5173).
